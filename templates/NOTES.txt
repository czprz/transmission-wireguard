Transmission is running behind a WireGuard sidecar with a chart-managed kill switch.

- Traffic can only leave the pod through the tunnel; if the tunnel goes down, it is blocked.
- Transmission starts only after the kill switch and the tunnel are up.
{{- if .Values.networkPolicy.enabled }}
- Egress NetworkPolicy allows only:{{ range include "twg.vpnEndpoints" . | fromJsonArray }} {{ .ip }}:{{ .port }}/udp{{ end }}
  (needs a CNI that enforces NetworkPolicy)
{{- else }}
- WARNING: networkPolicy is disabled. Only the in-pod kill switch protects against leaks.
{{- end }}
- DNS: {{ if .Values.wireguard.dns.override }}{{ join ", " .Values.wireguard.dns.nameservers }} through the tunnel{{ else }}WARNING: cluster DNS (lookups leak via CoreDNS's upstream and fail behind the kill switch){{ end }}
{{- $s := .Values.transmission.settings }}
{{- if index $s "rpc-host-whitelist-enabled" }}
- Web UI hostnames allowed without RPC auth: the Service name{{ if .Values.ingress.enabled }}, the ingress hosts{{ end }} and {{ index $s "rpc-host-whitelist" | default "nothing else" }}.
  Reaching it under another name (Gateway API, external proxy) gives HTTP 421; add the name to transmission.settings.rpc-host-whitelist.
{{- end }}
{{- if .Values.wireguard.existingSecret }}
- wg0.conf comes from Secret {{ .Values.wireguard.existingSecret }}: restart the pod after changing it
  (kubectl -n {{ .Release.Namespace }} rollout restart deploy/{{ include "twg.fullname" . }}).
{{- end }}

{{- if .Values.tests.enabled }}
Check for leaks from inside the cluster:
  helm test {{ .Release.Name }} -n {{ .Release.Namespace }} --logs

{{ end -}}
Verify the egress IP is the VPN's:
  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "twg.fullname" . }} -c transmission -- sh -c 'wget -qO- https://ifconfig.io'

Check the kill switch holds (must print "blocked"):
  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "twg.fullname" . }} -c wireguard -- ip link del wg0
  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "twg.fullname" . }} -c transmission -- sh -c 'wget -T 5 -qO- https://ifconfig.io || echo blocked'

Sidecar logs (refused configs show up as "[twg-firewall] FATAL"):
  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "twg.fullname" . }} -c wireguard
